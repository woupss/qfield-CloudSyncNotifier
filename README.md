With this plugin, after opening your cloud project, if a synchronization is pending, a popup will automatically appear, allowing you to either proceed with the synchronization or postpone it directly from the popup. Additionally, as long as a synchronization is pending, a button will be available to open the popup and proceed with synchronizing your cloud project.
